
🔍 Pencarian dan Eksplorasi Destinasi
Pengguna dapat mencari destinasi favorit dan menjelajahi berbagai kategori wisata seperti:

Pariwisata Alam & Ekowisata
Pariwisata Religi
Pariwisata Sejarah & Budaya
Pariwisata Kecantikan
Pariwisata Kuliner

📍 Rekomendasi Berdasarkan Lokasi
Menampilkan destinasi terbaik seperti di Pasuruan dan Malang, lengkap dengan rating, harga, dan gambar.

🎫 Sistem Pemesanan Tiket
Pengguna dapat melihat detail tempat wisata (contoh: Candi Pari), memilih tanggal kunjungan, serta melakukan pemesanan tiket secara langsung.

🌐 Fitur Tambahan
Menyediakan informasi fasilitas unggulan seperti WiFi dan penginapan untuk kenyamanan wisatawan.

🔐 Sistem Login & Autentikasi
Fitur login menggunakan email dan password serta opsi untuk lupa kata sandi.

📱 Desain UI/UX Modern
Antarmuka yang bersih dan navigasi intuitif menggunakan tab bar: Awal, Jelajahi, dan Akun Saya.

🛠️ Teknologi yang Digunakan:
Frontend: React Native
Navigasi: React Navigation
Komponen UI: Komponen kustom dengan layout responsif berbasis Flexbox
